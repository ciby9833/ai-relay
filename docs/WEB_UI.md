# Web UI 与国际化

管理员的「运行质量」入口包含「任务质量」「系统性能」两个视图。系统性能复用现有主题和三语言，显示主机／容器资源、到期任务、执行心跳和外部模型调用；默认未启用时显示明确空态。采集部署和指标口径见 [系统性能监控](MONITORING.md)。

## 界面语言

Web 支持英语（en）、简体中文（zh）、印尼语（id）。第一次访问跟随浏览器向网页提供的系统首选语言：`navigator.languages[0]`，不可用时读 `navigator.language`。区域标签会归一化，如 `en-GB` → `en`、`zh-TW` → `zh`、`id-ID` → `id`；目前所有中文变体显示简体中文。不支持的首选语言回退英语。

登录页和「设置 → 语言 → 界面语言」都可以选择跟随系统或手动选择语言。手动选择即时生效，保存在当前浏览器的 `relay.ui-language`，刷新后保留，并同步到同源的其他标签页。跟随系统模式响应浏览器的 `languagechange` 事件。浏览器禁止存储时仍可以在当前页面切换。

界面语言和已有的 Relay 回复语言是独立设置。切换界面不修改用户的回复偏好、不发送消息，不清空输入框或邮件草稿。历史消息、邮件、任务正文、审批业务字段和原始服务端诊断保留原文；这是界面国际化，不是历史内容的自动翻译。

## 实现

- `frontend/src/i18n.ts`：语言解析、持久化、插值、英文单复数和服务端文案描述符。
- `frontend/src/useLocale.ts`：React 订阅语言变化，根组件刷新视图而不重建组件状态。
- `frontend/src/locales/messages.ts`：现有中文固定文案作为键，英语和印尼语译文集中维护。
- `frontend/src/locales/common.ts`：带参数的文案及新增控件，包含中英印三种文本。
- `frontend/src/format.ts`：使用 `Intl` 格式化日期、时间、相对时间和列表。
- 后端为跟进事项的标准操作提示及「Relay 在办」的固定标题/说明提供可选 `*_ui` 描述符；前端按当前语言即时渲染。原有字符串字段继续保留，兼容旧客户端；业务名称只作为参数传入，不翻译、不改写。

新增固定文案必须提供全部支持语言；避免在组件模块初始化时调用翻译函数并缓存结果。固定状态映射保存文案键，在渲染时翻译。

## 运行质量与三层证据（2026-10-22）

管理员在左侧「运行质量」进入看板；普通用户不显示入口，统计和复盘接口也会校验管理员权限。

- 通知基线：最近 7／14／30 个完整日，与上一等长周期比较。每人按自己的时区分日，不含今天；零推送日计入日均，账号创建前的日期不计。统计已成功创建的飞书卡片，不代表用户已读；原地更新不额外增加推送。通知类型由现有标题分类，无法识别时计入「其他」。人工操作排除 `via=auto`，计操作次数而非去重事项数。
- 任务质量：按 UTC 完整日统计，展示分子、分母。目标核验未通过率是未通过的完成核验尝试 / 所有完成核验尝试；包括确定性拒绝和审核不可用。回读核验失败率是已知结果中的不一致次数 / 已知结果次数，读取失败、没有回读接口等单列为未知。标记标准和结束前重新回读均计一次尝试。
- 人工接管率：期间暂停并请求用户判断的去重任务 / 期间有运行或核验事件的去重任务。包括缺信息时的提问，因此不等于事故率。仅使用新版本采集到的事件，旧时间线不补算为「没有接管」。
- 误关闭率：人工确认误关闭 / 有明确复盘结论的已完成任务，按完成日期形成队列，采用当前最新复盘结论。未复盘和「证据不足」不计为正确；同时展示复盘覆盖率。这是已复盘样本的误关闭率，不是所有任务的总体误关闭率。保存复盘保留历史、记录管理员身份和依据，不自动重开任务。

新任务的每条验收标准可以要求执行证据、回复/确认证据或业务系统结果。任务详情中的「设置核验来源」允许用户绑定业务指标；后台执行者不能修改标准及来源。现阶段确定性业务核验支持**飞书表格数值单元格**，包含对象/指标口径、表格 token、工作表 ID、单元格及比较条件。选择「下降」时基线由系统回读，模型不能提交基线或当前值；目标阈值来自用户要求。修改标准或来源会清除旧证据，单纯修改别的条目保留未变条目的规则和证据。

标记业务条目时回读一次，结束前再回读一次；未绑定来源、基线缺失、回读错误、不是有效数值或比较失败都不能通过。普通操作必须已有成功回读，模型自己的计划或总结不能当作回复证据。独立审核同时检查原始目标是否被完整覆盖，不能只确认缩减后的清单；两轮不过自动暂停并请求用户判断。没有清单的旧任务也不能再跳过核验宣布成功。

独立审核仍可能使用相同基础模型，语义判断存在相关性错误。确定性比较证明的是绑定来源的读数满足规则；**来源是否代表正确网点、统计口径是否合适，以及底层业务数据是否及时准确，仍需核对**。其他业务系统尚未接入通用结果回读，不能把消息回复当作这类核验已经实现。

质量事件从部署后开始持续记录，不能从新代码推断生产效果已经改善。上线后应先观察覆盖率和样本量，再比较同等窗口；没有样本时显示「—」，不显示 0%。

本次验证：隔离数据库后端测试 159 项通过，浏览器测试 32 项通过，TypeScript 与 Vite 构建通过；检查了管理员桌面与 375px 手机布局。评测脚本扩充至 15 个场景并单独判断原始目标覆盖，但本次未运行真实模型评测，也未采集生产效果数据。

### 管理员界面与设计规则

本次从 Figma 文件的 Full screen、Inline card、Layout 与 Desktop web components 页面查找相关模式，采用 [Data viz 内容区](https://www.figma.com/design/RRfNMUS8opt9NpLV0Ovdlu/?node-id=467-39768)、[List row](https://www.figma.com/design/RRfNMUS8opt9NpLV0Ovdlu/?node-id=467-24659) 与 [TextInput states](https://www.figma.com/design/RRfNMUS8opt9NpLV0Ovdlu/?node-id=26-1764) 的上下文和截图作为参考。对应关系为内容层级与工具栏、可展开的紧凑列表、表单边框与焦点状态；沿用 Relay 的暖白／深色令牌、陶土强调色、衬线标题、既有按钮与侧栏。

默认只显示指标、分子分母、上一周期、复盘覆盖、通知用户行和任务行。计算公式与采集起点放在「统计口径」中按需展开；删除页面介绍、重复提醒和重复证据。业务指标用比较符号及初始值／回读值展示，不向用户重复展示内部 operator 名称。核验来源表单取消后再次打开会恢复已保存值。
