## 使用规则

- 每项任务以 ID 跟踪，实施时补负责人、提交/PR、验证环境和证据。没有证据不标完成。

- 任务可以分多个 PR，但功能开关、数据归属和单一写入路径必须一致。本文不自动授权上线或真实业务发送。
- 阶段 0 允许后续编写隔离测试、只读盘点工具及文档，不改变线上行为。迁移代码和业务改造从阶段 1 开始。

- 交付：依赖清单、数据归属表、现有接口清单、状态写入者表；记录当前提交号和迁移 head。
- 清单至少覆盖：必需飞书身份、token/scopes、全局飞书客户端、直接发送路径、按飞书回调推导的地址、联系人映射、后台用户扫描、提示词中的飞书假设。
- 验收：每处依赖都有当前入口、使用方、拟归属模块和兼容方式；明确 `Mission`、`FollowUp`、`ScheduledTask`、`PendingAction`、`GeneratedFile` 与账本的状态负责人。
- 验收：所有实际在用的飞书能力都进入迁移表，包含审批、群聊/私聊、邮件、日程、飞书任务、考勤、云文档、表格和多维表格；不能只盘点聊天工具。
- 证据：代码路径与调用点、只含计数和类型的数据盘点。凭证、实际私聊和文件正文不写入仓库。

### P0-03

**固定身份、授权和数据使用决策。**

- 涉及模块：`backend/app/api/auth.py`、`models.py`、`security.py`、`config.py`、`feishu/client.py`、`memory/service.py`、`automation.py`、`frontend/src/components/Login.tsx`。
- 交付：带决定人和理由的决策表。建议正式非飞书登录复用组织可用的 OIDC 身份服务；具体提供方、加入方式和运维依赖需要确认，不以开发免登录或虚构账号替代。
- 必须决定：组织成员加入/退出、管理员初始化、外部账号绑定冲突、最后一种登录方式的解绑、连接撤销和重连、已有会话失效方式、凭证迁移与密钥保留。
- 必须决定：既有会话保持云端；资料连接与聊天渠道分别授权；旧任务 grants 如何限定到原连接/账号/操作；读取、发送到模型和交付他人如何区分。
- 必须决定：断开连接、撤销权限、删除历史和删除记忆的区别；不能把“断开”描述成已经清除所有历史内容。确定数据保留和日志边界。
- 验收：所有影响 P1-01—P1-03 的未决项有明确决定；如身份提供方不可用，P1-02 保持阻塞，其他独立盘点仍可继续；不能默认为邮箱相同就合并。
- 证据：决策表只记配置名称和责任人，不记录真实密钥。本文中的建议尚不等于相关决定已作出。

### P0-04

**固定核心契约、能力清单和兼容方式。**

- 涉及模块：`backend/app/agent/tools/base.py`、`agent/loop.py`、`sources/base.py`、`proactive/actions.py`、`proactive/verify.py`、`missions/outcomes.py`、`proactive/push.py`、`home.py`、`frontend/src/api.ts`。
- 交付：接口与数据草案，至少覆盖执行身份、连接、能力描述、源事件、操作请求、核验结果和通知交付。列明必填字段、失败状态、可见范围、版本和去重键。
- 能力查询必须区分未配置、未连接、已过期、缺少权限、目标不可访问和可执行；执行入口再次检查，不能只靠模型工具列表隐藏。
- 源事件至少保留提供方、连接、外部 ID、事件时间、接收时间、事件类型、受众和来源引用。重复与更新分开处理；去重标识包含连接作用域。
- 通知至少区分业务事件 ID、接收者/受众、渠道交付 ID 和外部消息 ID；卡片回调仍验证实际操作人。
- 验收：普通能力不必包含飞书参数；飞书特殊操作能完整表达；未知结果不能被转为成功；旧 payload、卡片按钮与 API 有逐项兼容办法。
- 验收：旧单连接信号的迁移不产生第二份事项或重置同步游标；身份、任务、连接和资源权限都可在契约中核对。
- 客户端选型衔接：为 EX-00 固定设备执行请求/结果草案、授权与版本字段、三层证据映射、对照场景和性能预算；不要求此阶段实现 SDK、桌面宿主或原生辅助程序。
- 证据：固定契约及成功、未连接、撤权、未知结果、重复事件样例；只用虚构账号与内容。

- 验收：现有测试数据能恢复到隔离数据库并核对行数和关系；备份、密钥和凭证的恢复依赖有明确记录；没有访问生产服务或发真实通知。
- 验收：回滚明确区分代码降级、数据结构兼容和业务副作用核对。新非飞书用户、连接撤权等旧版本不理解的数据，要写明最低可回滚版本及阻断条件。

## 阶段 1：身份独立与飞书适配

### P1-01

**增加独立身份、组织、成员和个人助理记录。**

- 涉及模块：`backend/app/models.py`、`deps.py`、`api/auth.py`、`api/integrations.py`、质量/评估/管理接口，及 `backend/migrations/versions/`；新增独立身份和成员访问服务。
- 交付：按 P0 决策新增组织、成员、外部身份、连接和个人助理所需结构；旧用户映射至现有组织，原用户 UUID 不变。
- 验收：新用户无需填虚构 `feishu_open_id`；重复执行回填不重复建用户或助理；历史数据外键和归属保持一致。
- 验收：同名、同邮箱、不同租户或不同身份提供方的账号不静默合并；唯一约束包含提供方所需的租户/应用作用域。
- 验收：个人查询仍按用户限制；组织管理操作显式检查成员与角色；普通用户和另一组织管理员不能访问不属于自己的资源或统计。
- 验收：原管理员显式映射，不因新用户第一次登录就自动获得管理员权限；助理记录不改变已有个人主线。
- 验证方式：迁移往返/兼容测试、重复回填、无飞书用户、跨用户与跨组织负例；保留原主键对照结果。

### P1-02

**实现正式非飞书登录和独立会话生命周期。**

- 涉及模块：`backend/app/api/auth.py`、`security.py`、`deps.py`、`config.py`、`api/conversations.py`、`api/assistant.py`、配置模板；扩展 `backend/tests/test_routes.py`、`test_cross_entry.py` 等相关测试。
- 交付：接入 P0-03 确定的身份提供方；统一创建 Relay 会话；提供不调用飞书的用户信息接口。
- 验收：无飞书配置时正式登录、对话、记忆查看/删除和退出可用；生产环境不能通过 `dev-login` 绕过认证。
- 验收：验证身份提供方返回的发行方、受众、请求关联和有效期等适用条件；伪造、过期、重放或错组织响应不能建立会话。
- 验收：登录身份变更、成员停用与会话撤销按 P0 决策生效；飞书连接过期不会被误当作 Relay 登录过期。
- 验收：绑定新的登录方式要求证明当前 Relay 账号和外部身份的控制权，不按邮箱自动合并；失去唯一登录方式的情况有明确处理。
- 验证方式：隔离身份服务/协议夹具与端到端登录测试；另记试点身份服务实际联调证据，模拟测试不替代真实联调。

### P1-03

**把飞书身份绑定与资料/操作连接独立管理。**

- 涉及模块：`backend/app/feishu/client.py`、`api/auth.py`、`security.py`、`models.py`、`sources/people.py`、`config.py`；新增连接生命周期接口。
- 交付：绑定、连接、续期、权限变化、撤销、重连及状态查询；老飞书登录映射回原 Relay 用户；分离登录身份和业务能力授权。
- 验收：已有 token 迁移后仍能按原用户使用和刷新；凭证只在服务端加密存储，不进入普通 API、日志和模型上下文。
- 验收：撤销资料连接后，未执行操作和后台读取在执行前被阻止；不会回退到应用身份或另一个用户账号继续执行。
- 验收：撤销不删除用户、助理和历史；重连同一身份不创建重复用户；旧账号的待确认操作不会自动转给新绑定账号。
- 验收：并发刷新与迁移中只有一处权威 token；新开权限与原已授权权限可区分；连接与登录方式解绑规则符合 P0-03。
- 验证方式：过期、刷新失败、撤权、重连、账号切换、并发刷新、旧会话兼容；提供实际飞书授权联调记录但不保存凭证。

### P1-04

**用能力查询和路由替换核心中的必需飞书客户端。**

- 涉及模块：`backend/app/main.py`、`deps.py`、`agent/loop.py`、`agent/prompts.py`、`agent/tools/base.py`、`agent/tools/__init__.py`、`api/conversations.py`、`scheduler/worker.py`；现有飞书工具通过兼容适配器接入。
- 交付：与渠道无关的执行上下文，包含用户/组织、助理、任务、受众、授权和能力查询；按连接能力选择工具，不再给所有用户默认提供全部飞书工具。
- 验收：API 和 worker 在没有飞书配置时能运行无关任务；默认上下文、系统提示词和错误提示不假定用户一定有飞书。
- 验收：请求中伪造工具名、连接 ID 或任务 ID，不能越权调用；执行时再次检查连接与授权版本，不能仅依赖工具列表。
- 验收：同一核心任务通过网页入口和测试渠道适配器得到一致业务结果；现有工具 schema 与旧任务参数保持兼容。
- 验收：建立核心禁止直接导入/获取飞书实现的检查清单；暂留的兼容边界逐项列明，不以所有文件都搬目录作为目标。
